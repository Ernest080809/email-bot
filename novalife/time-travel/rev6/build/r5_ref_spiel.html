Das Spiel · Bauplannur bei „bauen“
Idee vom 27. September 2026 · gebaut wird nur nach der Entscheidung am 05.02.

Die Startseite wird ein Pixel-Spiel. Du läufst bei Sonnenuntergang durch ein Weizenfeld, an Jeans, Zipper und Polo vorbei, am Ende steht die Hütte. Das Feld öffnet am 29. März mit dem Countdown, die Tür der Hütte am 22. April: um 18:00 für alle mit dem Schlüssel aus der E-Mail, um 19:00 für alle anderen.

Gebaut wird in den Wochen, in denen die Fabrik näht: Woche 22 bis 27, rund 40 Stunden. Dazu ein Stiltest über Weihnachten. Kosten: ~20 € für Aseprite, aus dem Puffer.

Ob es gebaut wird, entscheidest du am Fr 05.02. (Woche 21). Bauen nur, wenn die Vorbestellung läuft und du sechs Wochen lang drei zusätzliche Abende hast. Mein Rat bei 1–2 Stunden am Tag: streichen oder Silhouetten-Version. Die Kampagne verkauft, das Spiel ist Kür. Ohne Spiel bleibt die Startseite die Warteliste, und am 22.04. um 19:00 veröffentlichst du das Theme „Drop 22.04.“.

Was der Besucher erlebt

Feldab 22.03. still · 29.03. öffentlich

Startbildschirm mit zwei Wegen: „Ins Feld“ und „Direkt zum Shop“. Im Feld: Tippen = hinlaufen. Tippen auf eine Station öffnet eine Karte mit Name, einem Satz, Preis und „22.04 · 19:00“. An der verschlossenen Tür: Countdown und das Formular „Hol dir den Schlüssel“.

Schlüssel22.04. ab 18:00

Wer über den Link aus der E-Mail T−1h kommt (?key=…), findet die Tür offen. Das ist dein Early Access, nur eben erzählt statt erklärt.

Offen22.04. ab 19:00

Die Tür ist für alle offen. Man startet direkt vor der offenen Tür, nicht am Anfang des Feldes. Drinnen hängt der Teppich an der Wand, darunter die drei Teile. Ein Tipp führt zur Produktseite.

Der Stack · entschieden

  1. Shopify-Theme-Kopie plus eine eigene Section. Kein zweiter Server, keine zweite Domain. Das Spiel liegt im Theme, die Bilder im Shopify-CDN, das Formular schreibt direkt in deine Kundenliste. Die Seite umbauen heißt, die Kopie zu veröffentlichen. Zurück geht es mit einem Klick auf das alte Theme.
  2. Phaser 3.90 als Spiel-Engine, lokal im Theme und nicht vom CDN. Phaser 4 gibt es seit April 2026, aber du brauchst nichts davon, und Claude Code kennt v3 aus Jahren voller Beispiele. Das heißt weniger erfundene Befehle und weniger Fehlersuche.
  3. Aseprite (~20 €) zum Zeichnen. Es exportiert PNG und JSON, die Phaser direkt als Animation liest (createFromAseprite). Die kostenlose Alternative LibreSprite bedient sich gleich, ist aber weniger komfortabel.
  4. Shopify CLI für die Vorschau am Handy, Git mit privatem GitHub-Repo als Rückgängig-Knopf und Claude Code im Terminal, im Theme-Ordner.
  5. Seitenansicht statt Draufsicht. Die Figur wird nur nach rechts gezeichnet, die linke Richtung spiegelt der Code. Das halbiert die Zeichenarbeit. Parallax-Ebenen im Sonnenuntergang sehen besser aus als jede Draufsicht, und zur Steuerung reicht ein Daumen.
  6. Hochformat 180 × 320 px, ganzzahlig hochskaliert. Fast alle kommen aus Instagram, also vom Handy.

Einmal einrichten · Befehle im Terminal

Mac-Terminal · Woche 22
# 1 · Shopify CLI installieren (Node.js LTS und Git müssen installiert sein)
npm install -g @shopify/cli@latest

# 2 · Vorher in Shopify: Live-Theme duplizieren, Kopie „Time Travel · Feld“ nennen
mkdir tt-feld && cd tt-feld
shopify theme pull --store DEIN-SHOP.myshopify.com
git init && git add -A && git commit -m "Ausgangsstand"

# 3 · Vorschau starten, den Link „Share your theme preview“ am Handy öffnen
shopify theme dev --store DEIN-SHOP.myshopify.com

# 4 · In einem zweiten Terminal-Fenster, im selben Ordner: Claude Code starten
claude

# 5 · Nach jedem Schritt, der auf dem Handy funktioniert
git add -A && git commit -m "Was jetzt geht"

# 6 · Fertigen Stand auf die Kopie hochladen
shopify theme push --theme "Time Travel · Feld"

Die fünf Prompts für Claude Code

Gib Claude Code einen Prompt pro Woche, nicht alle auf einmal. Der nächste kommt erst, wenn der letzte Schritt auf dem Handy funktioniert und committet ist.

Prompt 1 · Woche 22 · Graubox
Das ist mein Shopify-Theme, eine unveröffentlichte Kopie. Baue einen Graubox-Prototyp für ein Pixel-Spiel als eigene Section „tt-feld“:
- Phaser 3.90.0 als Datei in assets/, nicht vom CDN laden
- pixelArt: true, Hochformat 180×320 px, ganzzahlig auf die Bildschirmbreite skaliert
- Seitenansicht: ein Weg durch ein Feld, 4 Bildschirmbreiten lang, die Kamera folgt der Figur
- Figur = graues Rechteck 16×32. Steuerung mit einem Finger: Tippen irgendwo = Figur läuft dorthin
- Section-Einstellungen für den Theme-Editor anlegen: Drop-Zeit, Schlüssel-Code, Testmodus (Checkbox), drei Produkt-Links, drei Kartentexte, Link zur Kollektion
- templates/index.json zeigt nur diese Section
Keine weiteren Features. Erklär mir danach Schritt für Schritt, wie ich es mit shopify theme dev auf meinem Handy teste.
Prompt 2 · Woche 23 · Grafik
In assets/ liegen meine Aseprite-Exporte, je PNG + JSON: tt-figur, tt-himmel, tt-huegel, tt-weizen-hinten, tt-weizen-vorn, tt-huette. Ersetze die Grauboxen:
- Figur mit this.anims.createFromAseprite, Tags „stehen“ und „laufen“. Nach links = flipX
- Parallax-Ebenen mit Scroll-Faktor: Himmel 0 · Hügel 0.2 · Hütte 0.5 · Weizen hinten 0.8 · Weizen vorn 1.15 (vor der Figur)
- Weizen wiegt in einer 3-Frame-Schleife, pro Kachel leicht versetzt, damit es nicht im Gleichtakt zuckt
Die Pixel müssen scharf bleiben: keine Glättung, keine krummen Skalierungen.
Prompt 3 · Woche 24 · Stationen + Formular
Füge drei Stationen und die Hütte hinzu. Neue Dateien in assets/: tt-vogelscheuche, tt-zaun, tt-leine.
- Reihenfolge am Weg: Jeans an der Vogelscheuche, Zipper am Zaun, Polo auf der Wäscheleine, am Ende die Hütte
- Tippen auf eine Station: Figur läuft hin, dann öffnet sich eine Karte als HTML über dem Spiel, nicht im Canvas. Inhalt aus den Section-Einstellungen: Name, ein Satz, Preis, „22.04 · 19:00“
- An der Hüttentür: Formular „Hol dir den Schlüssel“ als echtes Shopify-Kundenformular ({% form 'customer' %}) mit dem Tag tt-feld. Nach dem Absenden: „Der Schlüssel kommt am 22. April per E-Mail.“
Zeig mir danach, wo ich die Anmeldungen in Shopify sehe.
Prompt 4 · Woche 25 · Tür, Zeit, Shop-Button
Baue die Tür-Logik mit drei Zuständen:
1. FELD: vor dem Drop. Tür zu, Countdown über der Tür
2. SCHLÜSSEL: ab 60 Minuten vor der Drop-Zeit, nur wenn die URL ?key= mit dem Schlüssel-Code aus den Section-Einstellungen enthält. Die Tür geht auf
3. OFFEN: ab der Drop-Zeit für alle. Der Spieler startet direkt vor der offenen Tür. Innen (tt-innen): Teppich an der Wand, drei Teile, Tippen = Produktseite
Die Uhrzeit kommt vom Server (Date-Header einer Anfrage an die eigene Domain), nicht vom Handy. Testmodus: ?t=<ISO-Zeit> überschreibt die Uhrzeit, aber nur, wenn in den Section-Einstellungen „Testmodus“ angehakt ist.
Dazu ein Button „Direkt zum Shop“, fest oben rechts, als normaler Link außerhalb des Canvas. Vorher zeigt er die Restzeit, ab Öffnung führt er zur Kollektion.
Und ein <noscript>-Block mit den drei Produktlinks, falls JavaScript fehlt.
Prompt 5 · Woche 26 · Prüfung
Prüf die Section wie ein strenger Tester: Gesamtgewicht aller Dateien, Zeit bis zum ersten Bild, Verhalten im Instagram-In-App-Browser, in iPhone Safari und Android Chrome, im Querformat, auf sehr kleinen Bildschirmen (iPhone SE) und ohne JavaScript. Gib mir die Probleme als Liste, sortiert nach Schwere. Repariere die ersten fünf, dann stopp und zeig mir, was du geändert hast.

Sieben Regeln · nicht verhandelbar

  1. „Direkt zum Shop“ ist immer sichtbar, als echter Link außerhalb des Spiels. Niemand muss durchs Feld laufen, um zu kaufen.
  2. Das echte Schloss ist Shopify, nicht das Spiel. Die Produkte werden per Future Publishing auf den 22.04. um 18:00 terminiert (Status Aktiv, Store-Zeitzone Berlin). Vor 18:00 kann also niemand kaufen, egal was die Uhr im Handy sagt. Zwischen 18:00 und 19:00 schützt nur der Schlüssel-Link, und wer die Produkt-URL kennt, kommt auch ohne ihn rein. Bei 100 Paar reicht das.
  3. Das Live-Theme wird nie bearbeitet. Gearbeitet wird nur an der Kopie. Das bisherige Theme bleibt als „PLAN B“ liegen.
  4. Nach jedem funktionierenden Schritt ein Commit. Claude Code wird Dinge kaputt machen. Mit Git kommst du zurück.
  5. Unter 1,5 MB, erstes Bild unter 2 Sekunden im Mobilnetz. Am Drop-Tag zählt Ladezeit mehr als Schönheit.
  6. Der wichtigste Browser ist der Instagram-In-App-Browser, nicht Safari und nicht Chrome. Dort wird getestet.
  7. Code-Freeze am 17. April. In der Drop-Woche wird am Spiel nichts geändert. Hängt am 22.04. etwas, veröffentlichst du PLAN B und fängst nicht an zu debuggen.
Risiken
1 · Die FinanzierungKritisch

Kapitalbedarf 9.380 €, Budget 4.500 €, Lücke 4.880 €. Sie kommt aus genau einer Quelle: den Vorbestellungen ab 14.01. Mindestens 10 bis zur Schwelle am 01.02., mindestens 32 bis zur Restzahlung am 19.03. Das Kontingent ist 35, der Puffer also 3 Paar.

Gegenmaßnahme: 50/50 statt 60/40 verhandeln (Woche 7). Schwelle am 01.02.: unter 10 keine Anzahlung, dann 75 Stück oder 2 Wochen schieben. Mehr als 25 Vorbestellungen bis zur Schwelle: Kontingent auf 45. Reicht es im März trotzdem nicht: Restzahlung gegen Versandnachweis oder Teilzahlung (Woche 26). Keine neue Stickerei ohne Gegenrechnung.

2 · EinfuhrumsatzsteuerHoch · neu

Als Kleinunternehmer kannst du keine Vorsteuer abziehen. Bei einer Fabrik in der Türkei sind 19 % Einfuhrumsatzsteuer auf rund 6.000 € Ware echter Aufwand, etwa 1.150 €. Das sind rund 8 Vorbestellungen, die es im Plan nicht gibt.

Gegenmaßnahme: Steuerstatus am 13.10. mit einem Steuerberater klären. Ergebnis geht in den Fabrikvergleich: Portugal kann trotz höherem Preis günstiger sein.

3 · Die Stickerei geht schiefKritisch

Der Stoff wellt sich, der Zuschnitt zieht sich zusammen, die Wäsche zerlegt das Garn oder schrumpft den Leinen-Patch. Jeder Fehler sitzt 100-mal.

Gegenmaßnahme: Gewaschene Stickproben (17.11.) vor dem Proto. Patch-Waschtest (26.11.). Proto mit Fit-Test (03.–05.12.). PP-Sample komplett (04.01.). Inline-Fotos zweimal (16.02., 01.03.). Endkontrolle vor der Restzahlung (19.03.).

4 · Ein Design, kein FallbackKritisch

Alle 100 Teile hängen an einem Ornament. Wenn es nicht ankommt, kommt nichts an.

Gegenmaßnahme: Validierung am 01.11. aus echten Content-Zahlen, bevor die Entwicklung bezahlt wird. Das ist der billigste Ausstieg im ganzen Plan.

5 · Die Warteliste ist zu kleinKritisch

100 Paar verkaufen ist eine Marketingleistung. Ohne rund 3.000 Adressen bleibst du bei 30–40 Paar.

Gegenmaßnahme: Zielkorridor 700 / 1.500 / 2.400 / 3.000 jeden Sonntag prüfen. Ab Dezember jede Woche ein Post mit echter Zahl. Creator-Anproben im Januar.

6 · Deine ZeitHoch · neu

1–2 Stunden pro Tag, rund 200 Stunden bis zum Drop. Fünf Tage sind länger: Shoot 20.02., Prüfung der Ware 31.03.–02.04., Drop und Packen 22.–24.04.

Gegenmaßnahme: Freie Tage jetzt schon einplanen (Aufgabe 05.03.), Packhilfe für den 23. und 24.04. Das Spiel nur bauen, wenn am 05.02. beides stimmt: Vorbestellung läuft und 3 Abende pro Woche sind frei.

7 · Termine der FabrikHoch · neu

Ramadan-Fest 08.–11.03. (Türkei), Ostern 26.–29.03. ohne Zoll und Zustellung. Ein Engpass im März schiebt die Ankunft hinter den Drop.

Gegenmaßnahme: Termine rund um das Fest am 04.03. schriftlich. Spätester Ankunftstermin für den Drop: 15.04. Später: Drop um eine Woche schieben oder mit Versand ab Ankunft, offen angekündigt.

8 · KommunikationGesteuert

Ein Herkunftsthema ohne Regel erzeugt politische Kommentarspalten statt Verkäufe.

Gegenmaßnahme: Subjekt ist das Muster, nicht das Volk. Keine Flaggenfarben. Nie „authentisch“. Gilt für jeden Post, jede E-Mail, jede Produktseite.

9 · Das Spiel bremst den KaufMittel

Eine Startseite, durch die man erst laufen muss, kostet am Drop-Tag Verkäufe.

Gegenmaßnahme: Nur bei „bauen“. Button „Direkt zum Shop“ immer sichtbar, ab 19:00 Start direkt vor der offenen Tür, PLAN B in unter einer Minute, Code-Freeze 17.04.
