# Time Travel — сайт с дверью

3D-сцена от первого лица (Three.js): идёшь по дорожке через пшеничное поле на закате к избе.
Дверь закрыта на замок. Попробуешь открыть — появляется отсчёт до дропа (22.04.2027, 19:00 CEST)
и предрегистрация. В 19:00 дверь открывается сама, кнопка ENTER ведёт в коллекцию.

Всё нарисовано кодом: картинок и 3D-файлов нет. Шрифты встроены в файл (DSGVO: без запросов
к Google). Внешний запрос только один: Three.js с cdn.jsdelivr.net.

## Звук
Всё синтезируется прямо в браузере, никаких аудиофайлов:
- музыка — оригинальный вальс ля минор, написан для этой страницы (гусли через Karplus–Strong,
  деревянная флейта, мягкий бурдон), куплет с флейтой чередуется с проигрышем;
- природа — птицы, сверчки, очень тихий ветер;
- шаги, стук двери, аккорд при открытии регистрации.

Ни сэмплов, ни чужой мелодии → нечего лицензировать (GEMA, Content ID в TikTok не на что матчить).
Звук включается только по клику («Play with sound» или «Sound» вверху) — браузеры иначе не дают.

## Файлы
- `src/page.html` — исходник (разметка, стили, сцена)
- `src/fonts/` — Bodoni Moda, Manrope, IBM Plex Mono (SIL Open Font License)
- `build.py` — собирает `index.html` (один файл для просмотра) и папку `shopify/`
- `index.html` — готовая страница целиком (для просмотра и любого обычного хостинга)
- `shopify/` — то же для Shopify: маленький шаблон + два ассета (у Shopify лимит 256 KB на шаблон)

После правок в `src/page.html`: `python3 time-travel/build.py`.

## Посмотреть
Открой `index.html` в браузере (нужен интернет для Three.js). Полезные метки в адресе:
- `#door` — сразу у двери
- `#open` — как выглядит открытая дверь после дропа
- `#waitlist` — сразу открыть регистрацию
- `#reset` — забыть, что ты уже зарегистрирован в этом браузере

Управление (30 м до двери): вперёд — держать кнопку / зажать экран, колесо вниз, свайп вверх, W / ↑;
назад — кнопка «←», колесо вверх, свайп вниз, S / ↓ (в том числе от самой двери).
Мышью (или пальцем) можно осматриваться.

## Запуск на Shopify (своя домена не нужна — страница живёт на novalife.store)
Shopify ограничивает Liquid-шаблон 256 KB, поэтому страница разбита на три файла в `shopify/`.
1. Online Store → Themes → `…` → **Edit code**.
2. **Assets → Add a new asset → Upload file**: загрузи `shopify/assets/time-travel.css`
   и `shopify/assets/time-travel.js`.
3. **Templates → Add a new template**: тип `page`, формат `liquid`, имя `time-travel`.
   Удали заготовку и вставь всё содержимое `shopify/templates/page.time-travel.liquid`. Сохрани.
4. Online Store → **Pages → Add page** «Time Travel», справа шаблон `page.time-travel`, Visible. Сохрани.
5. Открой `novalife.store/pages/time-travel`: пройди к двери, зарегистрируйся сам →
   в Customers появится клиент с тегом `time-travel-waitlist` и согласием на рассылку.
6. **Включи Double opt-in** (Settings → Customer privacy / Marketing) — в Германии обязательно.
7. Проверь Privacy Policy и Impressum (Settings → Policies) — ссылки в окне регистрации ведут туда.
8. Короткая ссылка для TikTok/Instagram: Online Store → Navigation → **URL Redirects**:
   `/timetravel` → `/pages/time-travel`.

После правок: `python3 time-travel/build.py` и заново загрузить изменённые файлы из `shopify/`.

22.04 в 18:00 — письмо через Shopify Email сегменту `customer_tags CONTAINS 'time-travel-waitlist'`.

## Настройки
Блок `CONFIG` в начале скрипта: даты, режим сохранения email (`shopify` / `endpoint` / `demo`),
ссылка на коллекцию, ссылки на Privacy и Impressum.

## Качество и скорость
- Колосья реалистичные (стебель, лист, колос с остью), но в шейдере каждый стебель расширяется так,
  чтобы на экране он был не тоньше ~1 px — поэтому при движении ничего не мерцает.
  Рядом с дорожкой — полная детализация, дальше — упрощённые пучки.
- Кроны деревьев: тёмное ядро + листья-карточки со сглаживанием краёв (MSAA на всех устройствах).
- Текстуры считаются параллельно в Web Workers, шейдеры компилируются асинхронно — загрузка
  примерно в 3–4 раза быстрее, чем раньше.
- Качество подстраивается само: если устройство не успевает, страница по шагам снижает разрешение,
  потом отключает свечение. Ещё легче — уменьши `near` / `far` в блоке `Q` (Quality tier).
